# Server-side programming

Eliom can be used as a traditional server-side Web framework, where the server generates the pages. These chapters are also the basis of client-server applications.

- [Services](./services/index.md) are the entry points of a Web site: how to create them, type their parameters, write their handlers, and link to them.
- [Sessions and server side state](./state.md): Eliom references keep data on the server for one user, one client process or a group of sessions, in memory or in a database that survives restarts.
- [Security](./security.md): what Eliom and Ocsigen Server take care of, and what is left to the programmer.
- [HTML widgets](./widgets.md): images, style sheets, scripts and menus.
