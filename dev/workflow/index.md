# Workflows

How to start, build, configure and deploy an Eliom project.

- [Distillery](./distillery.md): create a project from a template, then build and run it.
- [Mobile apps](./mobile.md): one code base for a Web application and Android or iOS apps.
- [Configuration & running](./configuration.md): Eliom's options in the Ocsigen Server configuration file, and options for your own modules.
- [Scalability](./scalability.md): running an application on several cores or servers.
